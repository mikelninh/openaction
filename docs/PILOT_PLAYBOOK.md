# First pilot playbook

OpenAction should be tested with real reviewers before it grows more features.

## 45-minute workshop

### 0–5 min — the 10-second problem
Show only:

```text
TODAY: each stakeholder sees one piece.
OPENACTION: everyone sees the same path, evidence and blockers.
```

Ask the participant to explain the idea back in their own words.

### 5–15 min — pick one real process
Choose a process the participant actually knows: hospital AI pilot, naturalisation case, building permit, procurement, SME automation, etc.

Map:
- desired outcome
- applicant/user
- accountable decision maker
- involved institutions/roles
- evidence required
- hard legal/physical constraints

### 15–30 min — destroy the Approval Graph
Ask:
1. Which gate is missing?
2. Which gate is unnecessary?
3. Who really owns each decision?
4. Which gates are independent and can run in parallel?
5. What evidence is routinely requested too late?
6. Which evidence already exists elsewhere?
7. Which approval is conditional, scoped or expiring?

### 30–38 min — Trust Passport reuse
For every evidence request, mark:
- reusable across projects
- organisation-specific
- case-specific
- sensitive / must stay at source

Calculate a first **evidence reuse rate**.

### 38–45 min — smallest safe next action
Define the smallest bounded pilot or process improvement that could responsibly happen next.

Do not ask “Would you buy this?” yet. Ask:

> **Would this shared picture reduce a real coordination problem in your work? Where exactly?**

## What to record

Never upload sensitive source material without an approved environment. For early workshops use synthetic or redacted examples.

Record only:
- domain
- number of gates
- missing/wrong gates
- reviewer roles
- reusable evidence count
- sequential vs independent gates
- late blockers remembered from past projects
- current lead-time estimate (clearly labelled participant estimate)
- smallest safe pilot
- participant confidence that the graph reflects reality

## Public proof bar

Before broad claims, aim for:
- 10+ expert workshops across at least 3 domains
- 100+ gates reviewed
- recurring primitives documented
- disagreements published, not hidden
- at least one real bounded pilot
- before/after lead-time and evidence-reuse measurements

## Success

The strongest result is not “everyone agrees with the schema.” It is:

> **People from different roles can finally point at the same object when they disagree.**

That turns hidden coordination into improvable infrastructure.
