# What works today — 1.0 RC1

## Usable now
- model an Action with evidence, permissions, risk and outcome
- model an organisation-wide Approval Path with owners/dependencies/SLAs
- package reusable review evidence in a Trust Passport
- issue a scoped Approval Receipt with conditions and expiry/revocation semantics
- calculate declared Change Impact so only affected gates are considered for reopening
- define a bounded safe-pilot profile
- validate Core and receipts with the CLI
- use JS, Python or Java reference SDKs
- run the deterministic 60-case Synthetic Pilot Lab

## Not yet proven
- real lead-time reduction
- real evidence-reuse rate
- whether different organisations agree on gate semantics
- independent implementation interoperability
- production signature integrations across multiple identity stacks
- governance durability beyond the founding maintainer

## Recommended use right now
Use RC1 for architecture workshops, pilot planning, adapter prototypes and synthetic/internal sandbox experiments. Do not present RC1 conformance as legal, clinical, security or regulatory approval.
