# COMMONS V0.8 — The Other Side

A self-contained playable vertical slice about creating a safe connection and hearing a voluntary reply.

## Play
Open `index.html` in a modern desktop or mobile browser. No account, wallet, dependencies, or external assets are required.

1. Drag the thread spool to the **shared willow** (or tap both on mobile). The private door cannot be used as an anchor.
2. Pull the middle knot to the **wind bell** (or tap both). Mia crosses when the bridge stabilises.
3. Tap or swipe the bridge to play a note. The cottage answers in the fictional story. Play again to awaken a wider world. The musical thread stays playable after the ending.

Optional synthesized sound is off until activated. Space/Enter supports the current game action; **J** opens the local field journal.

## What's new
A two-way musical thread instrument with tactile rope displacement and position-dependent notes; an answering call; a cinematic horizon reveal; reusable post-credits play; more forgiving touch hit targets, inverse-camera hit testing, and a stronger mobile tap implementation.

## Release notes and verification
Tested via Chromium and Playwright on desktop (1440×900), mobile (390×844), narrow mobile (320×640), and reduced-motion settings. Checks exercise drag/tap input, blocked private access, musical sequence, ending, replay, tamper detection, and absence of browser script errors. The source zip supplied with the ChatGPT release contains the runnable `release_test.py`.

This is a **fictional local simulation**, not a Midnight/Moriarty integration, real-world consent check, payment application, or independently verified ledger. Journal hashes reveal tampering of unchanged entries; they do not make the record immutable.
